CcPy
============================

Introduction
---------------------

CcPy ( **C**ruise **C**ontrol written in **Py**thon) is (yet another) automatic continuous integration Server.


Features
---------------------
* Runs on any unix-derived system
* Supports git and svn repositories
* Notifies on build results by email


Quick start
---------------------

Prerequisites:
* Python 3.x

To install:<br>
 <code># ./setup.py</code>

To start: <br>
  <code>#./ccpy.sh</code>
